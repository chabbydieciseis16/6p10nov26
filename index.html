📘 Lección 35: Entorno y Bloques de mBlock

Programar en mBlock es como jugar con bloques de construcción digitales. En lugar de escribir código difícil, juntas piezas de colores donde cada color tiene un trabajo específico:

🟡 Eventos (Amarillo)

Son los disparadores que le dicen al robot cuándo empezar (ejemplo: "Al presionar la bandera verde").

🔵 Acción y Movimiento (Azul)

Le indican al robot qué hacer físicamente, como mover motores a una velocidad o encender luces LED.

🟠 Control (Naranja)

Sirven para repetir órdenes (como el bucle "Por siempre") o tomar decisiones lógicas ("Si... entonces").

🩵 Sensores (Celeste)

Le permiten al robot sentir el mundo exterior, midiendo distancias o detectando colores e iluminación.

📘 Lección 36: El Sensor RGB Seguidor de Línea

Un robot funciona mediante un ciclo de 3 pasos: Entrada (Sensores) ➔ Proceso (Cerebro) ➔ Salida (Actuadores / Motores).

¿Cómo funciona la luz en el Sensor Seguidor de Línea?

El sensor emite un rayo de luz hacia el suelo y mide cuánta luz regresa reflejada:

  • Superficie Blanca: Refleja casi toda la luz. El sensor la interpreta como "Brillante".
  • Línea Negra: Absorbe la luz y no refleja nada. El sensor la interpreta como "Oscura".

Toma de Decisiones:

  • Si el sensor IZQUIERDO ve negro: El robot se está saliendo hacia la derecha. ¡Debe girar a la IZQUIERDA!
  • Si el sensor DERECHO ve negro: El robot se está saliendo hacia la izquierda. ¡Debe girar a la DERECHA!
  • Si ambos ven blanco: El robot camina derecho a velocidad constante.

📘 Lección 37: Algoritmos y Control en Bucle

Un algoritmo es una lista ordenada de pasos sencillos para resolver un problema.

Para seguir una línea, el programa necesita evaluar todo el tiempo si se sale del camino. Esto se logra metiendo los bloques condicionales (Si... entonces) dentro de un bloque Por siempre.

Además, calibrar la velocidad de los motores requiere un buen cálculo de potencia matemática para asegurar giros suaves.
